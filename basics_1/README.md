# Networking basics #1

Host name resolution, listing the IPs attached to a machine, and listening on a port.

## Files

| File | Description |
| ---- | ----------- |
| `0-change_your_home_IP` | Resolves `localhost` to 127.0.0.2 and `facebook.com` to 8.8.8.8 |
| `1-show_attached_IPs` | Displays all active IPv4 IPs of the machine |
| `2-port_listening_on_localhost` | Listens on port 98 on localhost |
